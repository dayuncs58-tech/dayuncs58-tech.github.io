# Day Lee — Accounting & Economics Portfolio

A responsive, recruiter-focused one-page portfolio made with plain HTML, CSS and JavaScript. No Base44, build process, or paid framework needed.

## Preview locally

Open `index.html` in a browser. An internet connection loads the optional Google Fonts; fallback fonts work offline.

## Personalize before sharing

1. Edit `index.html` and replace all placeholders in square brackets: university, graduation, coursework, experiences, and skills.
2. Replace `your.email@example.com` with your professional email address.
3. Replace `https://www.linkedin.com/` with your actual LinkedIn profile URL.
4. Replace suggested project cards with projects you've completed. Do not present suggested work as finished work.
5. Update the introductory text if your major is still changing. The sample does not claim completion of any degree.
6. Add a PDF résumé when ready, for example `resume.pdf`, and add this link to the navigation or hero: `<a href="resume.pdf" target="_blank" rel="noopener">View résumé</a>`.
7. Verify spelling, mobile layout, and link destinations.

## Publish on GitHub Pages

1. Create a GitHub account or log in to an existing account at https://github.com.
2. Create a PUBLIC repository named `YOURUSERNAME.github.io` (replace YOURUSERNAME with your exact GitHub username).
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root, then commit.
4. Go to repository **Settings → Pages → Build and deployment**.
5. Set Source to **Deploy from a branch**, Branch to `main`, folder to `/(root)`, and Save.
6. Open `https://YOURUSERNAME.github.io/` after GitHub completes publication.

For a different repository name, the resulting URL is usually `https://YOURUSERNAME.github.io/REPOSITORY/`.

Official guidance: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Customize design

Edit the variables at the top of `styles.css` to change colors. Hero copy is near the top of `index.html`. The mobile menu is controlled by `script.js`.

## Privacy

Publishing to GitHub Pages makes this page public. Include only contact details, documents, and information you intend to make public. Never upload passwords, account numbers or confidential coursework or business records.
